# Decision provenance

No imported ChatGPT decision exists. Actual user approvals and autonomous
implementation choices are distinguished in shared/DECISIONS.md.

For a future imported decision, retain its real source message, problem ID,
problem hash and active version. Verify all three against the current problem
before execution. Unknown/inaccessible sources remain BLOCKED or PARTIAL; they
must not be reconstructed as verbatim history. Major user approval boundaries
continue to apply even if an external AI recommends an action.
