# 本地附件、公开下载和保密边界清单

> 不要把新对话的用户上传赛题文件路径当成用户 Windows 文件路径。PDF 已在本包提供；其余**官方私有材料**必须由用户或 Codex 从用户授权的本地实际路径导入。

## 1. 启动之前人工准备（P0）

| 项目 | 必须性 | 推荐放置 | 注意 |
|---|---|---|---|
| 本包 `OFFICIAL_RULES_用户提供.pdf` | 必须 | `bootstrap/` | 比赛正式赛题原件，全文核对 |
| 本包 01–06 指令与检查文件 | 必须 | `bootstrap/` | 版本固定；未来改动留记录 |
| `PROJECT_INPUTS.yaml` 真实填写 | 必须 | `bootstrap/` | 必须指明 PROJECT_ID、自己的正式 repo、绝对 workspace |
| 组委会 E203 正式平台工程 | 必须 | `inputs/official/platform/` 或真实绝对路径 | 官方平台优先，不等于开源 Hummingbird |
| 组委会 SRAM 宏 RTL/仿真模型/面积数据 | 必须 | `inputs/official/sram/` | `16-bit × 128/1024/4096`，注意单/双端口与时序 |
| 组委会标准单元 Liberty/映射约束 | 正式 PPA 必须 | `inputs/official/pdk/` | **不可公开上传**，保留版权许可 |
| 组委会 SDC/综合脚本/工具说明 | 正式 PPA 必须 | `inputs/official/flows/` | 防止伪约束或错误面积口径 |
| 合法可用 EDA 工具/许可证 | 正式 PPA 必须 | 安装或受控路径 | 避免泄露 license/server/账号；禁止擅自付费 |
| 官方参数加载/SoC 仿真环境 | 必须 | `inputs/official/test_env/` | 赛题明确提供，按原始访问入口验证 |
| 官方赛程通知/报名及提交规则 | 推荐 | `inputs/official/notices/` | 此 PDF 未明确报名截止日期及详细格式 |

**许可/隐私**：官方库文件、商业许可、密钥和竞赛受限资料不能自动进入公共 GitHub；建议 `.gitignore` 保护 `inputs/official`, `external/cache`, `toolchains`, `envs`, 以及大规模日志。Git 可登记源文件 hash、版本和获取步骤，不公开原始敏感字节。

## 2. Codex 可合法自动下载（P0）

1. E203 开源参考：`https://github.com/riscv-mcu/e203_hbirdv2.git`。应 `git clone` 到 `external/src/e203_hbirdv2` 并记录**具体 commit SHA**；开源项目 `master` 可能变更，不能直接用作比赛正式平台。
2. 软件 SDK：`https://github.com/riscv-mcu/hbird-sdk.git`。只在与官方平台/编译配置兼容时使用，保留 SHA、License。该 SDK 自有修改的 NMSIS，不等价于上游任意 NMSIS 版本。
3. ARM 模型：`https://github.com/ARM-software/keyword-transformer.git`，必须 checkout **`237e4097`**。检查 `models_data_v2_12_labels/kwt1/` 下 `flags.json`、`best_weights.*`、`labels.txt`；README 列表与 flags 可能不一致，以真实 checkpoint 的形状和竞赛规则共同核验。
4. Speech Commands V2：按 ARM 仓库对应官方 Setup 下载 `speech_commands_v0.02`，记录官方镜像 URL 和 checksum；大体积数据不入 Git。数据集存在下载/许可限制时，不使用不明镜像或私有资源绕过。
5. Verilator: `https://verilator.org`；Icarus Verilog: `https://steveicarus.github.io/iverilog/`；GTKWave：可信发行渠道。
6. 开源辅助综合：Yosys、OpenSTA 仅用于**预检查或官方允许的流程**，不得用不匹配的标准单元库/宏模型替代正式评分。
7. RISC-V GNU 工具链：优先组委会工具链，其次已验证兼容的 RISC-V bare-metal compiler，记录 `-march/-mabi`、sysroot、ELF/HEX 转换方式。
8. Python：独立 venv + `requirements.lock`/`pip freeze`；对旧 KWT 源码和 TensorFlow 版本做最小兼容验证后固定，不强制安装最新版。禁止训练/微调指定预训练模型。

## 3. 可作为研究参考（P1，仅节制下载）

- KWT-Tiny：`https://arxiv.org/abs/2407.16026`（模型压缩和重训练方案不可直接用于本赛题）。
- Transitive Array（ISCA 2025）：`https://dspace.mit.edu/entities/publication/105e0a01-8076-4c34-bf38-cbec6c3d863e`（结果复用，机制参考）。
- FlexViT (2026)：`https://arxiv.org/abs/2606.31938`（数据流切换、分块思路，平台不等价）。
- 2025 NEWCAS transformer 线性层数据流研究：`https://ieeexplore.ieee.org/abstract/document/11107035`（需记录访问级别）。
- 2026 端侧 Transformer FPGA 综述：`https://doi.org/10.1016/j.sysarc.2026.103841`（框架和分类研究）。
- 2026 KWS ASIC：`https://ieeexplore.ieee.org/document/11259055/`（跨域设计，仅背景参考）。

必须查证“往届作品”是否有来源、项目代码、成绩或复现记录；没有可靠证据不要假称研究了获奖作品。

## 4. 官方资料尚未具备时的阻塞处理

- 官方 SoC 平台缺失：`BLOCKED_OFFICIAL_PLATFORM`；可以单独做 RTL，但不能完成官方 SoC 验收。
- 真实 KWT checkpoint 读取失败：`BLOCKED_MODEL_CHECKPOINT`；不得硬编码假张量推进。
- SRAM 宏模型缺失：`BLOCKED_MEMORY_MACRO`；只能做功能模型，正式面积/功耗不可验收。
- PDK/Liberty 缺失或未授权：`BLOCKED_ASIC_LIBRARY`；仅可做非正式综合。
- 正式功耗工具/SAIF 覆盖无效：`BLOCKED_POWER_EVIDENCE`；不可捏造平均功耗和 J/task。
- 官方评测清单未发布：`UNVERIFIED_OFFICIAL_600_SAMPLES`；用允许的验证集预演，不能冒称最终统一评测通过。

## 5. 下载保存的证据格式

生成 `external/SOURCES.lock.json` 或 Markdown/CSV，至少记录 `resource_name, upstream_url, commit_or_version, sha256, license, downloaded_at, local_relative_path, reproduction_command, is_official, redistribution_allowed`。

禁止自动执行未知来源的 `curl | bash` 无校验脚本。下载后先读取/检查脚本再执行；所有运行和工具版本存入 `v1/reports/environment/`。
